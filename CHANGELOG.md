# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-18

### Added
- Initial release with 537 free LLM models from 30+ providers
- CLI with 6 commands: `list`, `search`, `info`, `providers`, `compare`, `random`
- Programmatic API: `all`, `search`, `get`, `providers`, `byProvider`, `random`, `meta`
- JSON output mode (`--json`) for scripting
- Data synced from [freellm.net](https://freellm.net)
